Informations

ID de la Box :

Doit être unique. Utilisez un nom descriptif comme "BUREAU_01" ou "SALLE_SERVEURS".

Capteurs :

Les capteurs sélectionnés seront créés avec des valeurs par défaut. Vous pourrez les modifier via les trames 3A.

Relais :

Tous les relais seront initialisés à l'état OFF (0).

Compteurs :

Entrez les valeurs initiales pour chaque compteur sélectionné.
